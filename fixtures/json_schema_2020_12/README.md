# JSON Schema 2020-12 oracles

Unmodified cases from [JSON-Schema-Test-Suite](https://github.com/json-schema-org/JSON-Schema-Test-Suite/tree/55719286c33ae0d1823bfb65fea10338a19bc37c/tests/draft2020-12), revision `55719286c33ae0d1823bfb65fea10338a19bc37c`, retrieved 2026-10-15. The accompanying MIT license applies. The retained files cover static/dynamic references, boolean schemas, conditionals and unevaluated properties. The unmodified `contains.json` from the same revision was added on 2026-11-02 for production migration count oracles. `tests[].valid` is the oracle; an exception or unavailable resource is not an accepted rejection or a skipped success.

The registered production evaluator and migration suites under `tools/contract_engine/` consume these unchanged oracles, including `test_evaluation.cjs`, schema resource views, dynamic references and contains/unevaluated conversion cases. Historical candidate-only evaluator probes have been removed; their results are not production qualification.
